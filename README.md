# ⚖️ Pakistani Legal AI Assistant

An AI-powered chatbot that answers questions about the Constitution of Pakistan in plain English.

## 🔗 Live Demo
[Click here to try the app](https://pakistani-legal-assistant-hylbgtkir3appdtcakygasr.streamlit.app/)

## 💡 What it does
- Ask any question about the Constitution of Pakistan
- Get clear, plain English answers
- See exactly which pages the answer came from

## 🛠️ Tech Stack
- Python
- Streamlit
- LangChain
- FAISS
- Groq API (llama-3.3-70b)
- HuggingFace Embeddings

## 🚀 How to Run Locally
1. Clone the repo
2. Install dependencies:
   pip install -r requirements.txt
3. Add your Groq API key in .env:
   GROQ_API_KEY=your_key_here
4. Run:
   streamlit run app.py
